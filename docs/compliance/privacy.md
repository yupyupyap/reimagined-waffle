# Privacy And Local-First Policy

LocalChessEngine is designed as a local-first desktop engine and GUI. The v0.2
engine, GUI, trainer smoke flows, and validation scripts do not send telemetry,
game records, positions, PGN files, training data, or preferences by default.

## Default Behavior

- The UCI engine reads commands from stdin and writes UCI output to stdout.
- The Qt GUI stores preferences locally through Qt settings and launches the
  configured UCI engine as a child process.
- PGN load/save, NNUE files, datasets, match logs, and validation reports are
  local files selected or generated by the user.
- No analytics SDK, crash reporter, telemetry endpoint, account system, or
  background network service is configured.

## Explicit Network Or External Actions

The following paths are intentionally explicit and operator-driven:

- `localchessengine-export-lichess-fens` can stream a Hugging Face dataset only
  after the user runs that command and installs the optional trainer extra.
- OpenBench integration under `tools/openbench/` requires the user to configure
  an external OpenBench checkout/server and run its worker or wrapper commands.
- Cute Chess match execution is local unless the user points tooling at external
  engines, files, or infrastructure.
- Apple notarization uses `xcrun notarytool` only during release packaging and
  requires a local keychain profile or Apple Developer credentials supplied by
  the release operator.

## Release Validation

Before public distribution, TASK-047 validation must include source review for
URL/network call sites and generated evidence showing that optional dataset or
OpenBench paths are documented as explicit user actions.
